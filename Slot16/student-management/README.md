# Student Management System

Student Management System developed with JavaFX, Spring Boot,
Spring Data JPA, SQL Server and Maven.

## Requirements

- JDK 21
- Maven 3.9+
- SQL Server
- JavaFX 21

## Project Structure

The project contains two Maven modules:

- `data-module`: Entity, Repository, Service and tests.
- `ui-module`: JavaFX user interface and Spring Boot bootstrap.
